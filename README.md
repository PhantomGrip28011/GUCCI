# GUCCI

راه‌اندازی پنل **3x-ui** با داکر — پنل **فقط روی پورت `1111`** بالا می‌آید (به‌جای پورت پیش‌فرض 2053).

## نحوه کار

- `entrypoint.sh` موقع استارت کانتینر و **قبل** از بالا آمدن پنل، پورت آن را روی `1111` تنظیم می‌کند.
- فقط پورت `1111` اکسپوز می‌شود.

## اجرا روی VPS

```bash
docker build -t gucci .
docker run -d --name gucci -p 1111:1111 --restart always gucci
```

بعد پنل را باز کنید:

```
http://<IP>:1111/
```

## اجرا روی پلتفرم‌های ابری (Render / Koyeb / ...)

1. ریپو را به سرویس وصل کنید (Deploy from Git, نوع Docker).
2. اگر پلتفرم از شما پورت خواست، مقدار `1111` را وارد کنید.
3. بعد از دیپلوی، دامنه‌ای که پلتفرم می‌دهد مستقیماً به پنل وصل می‌شود.

## ورود به پنل

- یوزرنیم/پسورد پیش‌فرض نصب تازه: `admin` / `admin`
- ⚠️ حتماً بعد از اولین ورود، یوزرنیم و پسورد را عوض کنید (Settings).

> داده‌های پنل (کاربرها، اینباندها و ...) در `/etc/x-ui` ذخیره می‌شود.
> روی VPS حتماً Volume وصل کنید: `-v x-ui-db:/etc/x-ui`
